# 暮光花园 · 双人闯关版

`future-tank-defense` 是一款基于 XGo / SPX 的俯视角本地双人合作生存射击游戏。玩家驾驶花园主题战斗单位，在不同场景中移动、射击、使用技能和拾取道具，保护花房并击败三关领主。

当前版本：`v0.3.0`

## 核心玩法

游戏流程：

`选择人数与关卡 → 移动躲避 → 射击僵尸 → 获取金币和道具 → 购买武器升级 → 保护花房 → 挑战 Boss`

- 支持单人和同一键盘本地双人合作。
- 支持三关场景：暮光花园、寒霜庭院、熔岩遗迹。
- 每关先面对有限数量的先锋僵尸，清除后进入 Boss 战。
- 前两关 Boss 击败后可以继续下一关；第三关 Boss 击败后完成本次闯关。
- 可以从选关界面直接选择任意一关开始。

## 双人合作

- 1P 和 2P 各自拥有独立生命、射击冷却、大招冷却、受伤保护和道具增益。
- 双方共享金币和武器等级，任意一名玩家购买升级后立即对双方生效。
- 队友之间不会互相伤害。
- 一名玩家出局后，另一名玩家可以继续战斗；双方都出局或花房被摧毁时失败。
- 进入下一关后双方恢复生命，金币、武器等级、得分和击杀数保留。

## 武器商店与升级

击杀敌人获得团队共享金币，在战斗中按 `B` 打开武器商店：

| 武器等级 | 价格 | 效果 |
| --- | ---: | --- |
| 0 | 免费 | 单发子弹，基础伤害 1 |
| 1 | 300 | 三发扇形导弹，左右各偏转 16° |
| 2 | 600 | 五发扇形导弹 |
| 3 | 1000 | 五发导弹，基础伤害提高到 2，射击间隔降低 |

- 普通敌人击杀获得 100 金币。
- Boss 击杀获得 900 金币。
- 每个敌人只会结算一次金币。
- 金币独立于得分和击杀数，最多保存 9999。
- 只能按顺序购买下一级，不能重复购买。
- 金币不足时不会扣款；达到等级 3 后显示武器已满级。
- 辣椒增益会在当前武器伤害基础上额外增加 1 点伤害。
- 子弹在发射时保存伤害值，发射后的子弹不会因后续升级或增益变化。
- 商店打开后战斗和游戏计时冻结，允许购买；关闭后继续战斗。

## 玩家操作

| 功能 | 1P | 2P |
| --- | --- | --- |
| 移动 | `WASD` | 方向键 |
| 射击 | 空格 | `J` |
| 爆裂种子大招 | `E` | `K` |

公共操作：

- `B`：打开 / 关闭武器商店。
- `1` / `2` / `3`：购买对应武器等级。
- `P`：暂停 / 继续。
- `R`：重开当前关卡，重置金币、武器等级、生命、得分、击杀数、技能和道具状态。
- `M`：返回人数与关卡选择界面。
- `Enter`：通关后进入下一关。

选关界面：

- `1`：单人模式。
- `2`：双人模式。
- `F` / `G` / `H`：选择第 1 / 2 / 3 关。
- `Enter`：开始游戏。

## 敌人与 Boss

| 敌人 | 初始血量 | 行为 |
| --- | ---: | --- |
| 重甲僵尸 | 5 | 移动较慢，可承受多次攻击 |
| 疾跑僵尸 | 1 | 快速接近玩家 |
| 冲锋僵尸 | 3 | 锁定方向、显示预警并进行冲刺 |

Boss 具有独立造型和顶部血条，会追踪存活玩家并进行孢子弹幕攻击。Boss 生命降至一半后会移动加快并追加攻击轮次。

## 道具与技能

| 道具 | 效果 |
| --- | --- |
| 坚果盾 | 抵挡 3 次伤害，持续时间有限 |
| 樱桃炸弹 | 拾取后立即爆炸，对范围内敌人造成伤害并破坏树篱 |
| 蘑菇 | 移动速度提高 55%，持续 8 秒 |
| 辣椒 | 普通射击和导弹每发额外增加 1 点伤害，持续 8 秒 |

- 爆裂种子开场即可使用，冷却约 5 秒。
- 1P 使用 `E`，2P 使用 `K`，双方冷却独立。
- 爆裂种子命中后范围爆炸，可伤害敌人、破坏树篱并清除孢子。
- 道具会在地图中随机生成，靠近后自动拾取。

## 地图与战斗规则

- 三关拥有不同的障碍布局和场景风格。
- 树篱可以被攻击破坏，经过延迟后逐步再生；再生时会检查玩家和敌人占位，避免直接困住角色。
- 玩家受到攻击后会获得短暂保护。
- 敌人被击败后经过消散和传送阶段，再从安全位置补充。
- 花房被敌方孢子命中后，本局失败。
- `P` 暂停时，移动、攻击、敌人行为、道具持续时间、技能冷却和树篱生长都会停止。

## HUD 与界面

战斗 HUD 显示：

- 玩家生命和护盾状态。
- 得分和击杀数。
- 技能冷却。
- 当前金币。
- 当前武器等级。
- 道具增益和持续时间。
- Boss 血条和攻击预警。

商店界面显示当前金币、当前武器等级、可购买等级、价格、升级效果、购买按键和关闭提示，并提供购买成功、金币不足和武器满级反馈。

## 运行方式

1. 打开 [XBuilder](https://x.qiniu.com/)。
2. 导入项目目录中的 `暮光花园-双人闯关版.xbp`。
3. 点击游戏区域后，使用键盘选择模式和关卡。
4. 按 `Enter` 开始游戏。

源码入口为 `main.spx`，主要模块包括：

- `main.spx`：输入、状态、移动、战斗、敌人、Boss、金币、武器商店、道具和关卡流程。
- `Actor.spx`：玩家、敌人、子弹、道具和动画表现。
- `Campaign.spx` / `Scene.spx`：关卡、场景和 Boss 状态显示。
- `Health.spx` / `Hud.spx`：生命条、得分、金币和武器等级 HUD。
- `Atmosphere.spx` / `Ability.spx` / `Buff.spx`：环境、技能冷却和增益显示。
- `Frame.spx` / `Notice.spx`：界面框架和商店、状态提示。
