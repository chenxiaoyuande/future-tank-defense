# 未来城市无人坦克防御战

> 科幻题材的俯视角网页坦克防御游戏，让创意通过 Vibe Coding 变成可玩的作品。

## 项目状态

项目目前处于需求规划阶段，仓库暂未包含可运行的游戏代码。下述玩法、按键和功能均为设计目标，实际实现后将同步更新。

## 项目简介

玩家驾驶无人坦克，在未来城市中抵御敌方坦克，保护地图下方的能源核心。游戏以经典坦克防御玩法为基础，计划加入激光炮、能量盾、可破坏建筑和随机事件。

第一阶段优先完成一局可玩的游戏，不依赖复杂美术素材或在线服务。

## 核心玩法

- 控制坦克移动与射击，利用障碍物保护自己和能源核心。
- 敌方坦克从地图上方分批生成，向能源核心推进并发起攻击。
- 不可破坏障碍阻挡移动和炮弹，可破坏建筑受到攻击后损坏或消失。
- 玩家和能源核心分别拥有生命值。
- 本关所有敌人生成完毕且被消灭后，玩家获胜。
- 玩家生命值归零或能源核心被摧毁时，游戏失败；失败判定优先于胜利判定。
- 支持暂停、继续和重新开始；重新开始时重置地图、生命值、敌人和计分等状态。

## 计划操作方式

| 操作 | 按键或入口 |
| --- | --- |
| 移动并调整朝向 | WASD / 方向键 |
| 发射炮弹 | Space |
| 暂停 / 继续 | P / 页面按钮 |
| 重新开始 | 结算页按钮 |

实际按键以实现后的游戏内说明为准。激光炮等扩展技能的操作方式将在实现时补充。

## 技术与运行

当前技术栈、依赖和启动方式尚未确定。游戏代码落地后，将根据实际项目配置补充环境版本、安装依赖、开发启动、构建和测试命令。

获取仓库：

```bash
git clone git@github.com:chenxiaoyuande/future-tank-defense.git
cd future-tank-defense
```

私有仓库需要具备访问权限，并已配置 GitHub SSH 公钥。仅克隆当前仓库还不能运行游戏。

## 开发协作流程

1. 在 XBuilder 中提供需求并生成游戏代码；XBuilder 不负责连接本仓库。
2. 将生成的源码导出或同步到本地仓库，保留必要的依赖配置和资源文件。
3. 在本地检查代码、修复问题并验证玩法。
4. 提交并推送功能分支，通过 Pull Request 审查后合并到 `main`。
5. 回到 GitHub 检查提交记录，确认代码已保存；页面预览成功不代表源码已同步。

建议功能分支命名：

- `feature/tank-game-core`
- `feature/laser-shield`
- `fix/restart-state`
- `docs/project-readme`

提交信息示例：

- `feat: 实现坦克移动和射击`
- `fix: 修复重新开始后敌人未重置的问题`
- `docs: 更新运行说明`

多人协作时应先明确文件和功能分工，避免同时覆盖同一模块。不要将未经验证的生成结果直接视为已完成。
