# 暮光花园 v1.5.0 · 实机演示解说稿

成片：1080p / 24 fps，约 4 分 36 秒。
旁白：macOS Tingting 普通话合成语音。
画面全部取自用户提供的 XBuilder 录屏；部分菜单短暂停帧，战斗片段原速。
本版配功能标题与要点，未包含逐句语音字幕。

## 00:00 暮光花园

欢迎来到暮光花园，三职业觉醒版。这是一款花园主题的俯视角守城游戏。接下来，通过实际操作，看看它的职业、合作与闯关玩法。

原录屏取材：23–28 秒。

## 00:16 读档与备份

读档页面可以继续上次的远征。游戏保存的是关卡起点，以及金币和职业进化。想迁移进度，还可以导出备份。这是本机存档，不是云存档。

原录屏取材：2.1–4.2 秒。

## 00:33 语言设置

设置页面支持中文和英文切换，方便不同玩家使用。语言偏好会随本机进度保存，下一次进入时继续生效。

原录屏取材：6.1–10.2 秒。

## 00:47 进化实验室

实验室里，豌豆、蘑菇和西瓜拥有各自的进化路线。每条路线从基础形态开始，可以逐档升级。金币由团队共享，但购买只作用于当前选择的职业。

原录屏取材：12.1–22.0 秒。

## 01:04 二十关远征

选关页面展示二十张地图，分布在四个主题区域。打勾的是已经完成的关卡，带锁的关卡需要继续闯关解锁。已解锁的地图可以反复挑战。

原录屏取材：28.3–38.1 秒。

## 01:20 选择守护者

进入战场前，可以选择单人或双人。三种职业各有特点：豌豆擅长连续射击，蘑菇通过穿透和孢子云持续输出，西瓜使用越墙抛射。双人模式下，可以切换玩家，分别搭配职业。

原录屏取材：39–62 秒。

## 01:43 双人守城

进入战场后，两名玩家在同一张地图中合作。双方拥有独立生命和技能冷却，攻击不会伤害队友。可以分守两侧，一边清理僵尸，一边保护底部的守护目标。

原录屏取材：65–84 秒。

## 02:02 守住脑子

底部的脑子是必须保护的目标。它自带屏障，累计被僵尸啃咬三秒后消失。及时清理靠近的敌人，就能中断损耗；屏障消失后，再被接触就会失败。

原录屏取材：95–112 秒。

## 02:20 道具与强化

战斗中会出现随机道具，包括坚果盾、樱桃炸弹、加速蘑菇和增伤辣椒。谁拾取，谁获得对应效果。击退敌人还能获得金币，为后续永久进化积累资源。

原录屏取材：207–224 秒。

## 02:39 敌人与掩体

敌人有重甲、疾跑和冲锋三种行为。面对冲锋预警，要及时改变位置。地图上的树篱能被破坏，也会重新生长；符文石则持续阻挡，让路线选择成为战斗的一部分。

原录屏取材：250–268 秒。

## 02:58 荆棘召唤者

第五关迎来荆棘召唤者。绿色符阵出现后，领主会召唤援军，玩家需要在攻击领主和清理小怪之间分配火力。画面顶部显示领主血量，预警给了我们反应时间。持续输出、守住后方，就能完成这一关。

原录屏取材：298–324 秒。

## 03:24 暂停与继续

需要暂时离开时，按下暂停。战斗与计时都会停止，再次按下，就能继续远征。

原录屏取材：327.7–330.1 秒。

## 03:35 寒霜庭院

通过前一个主题后，我们进入寒霜庭院。场景和地图布局随之变化，双人组合也可以重新选择。过关接续时恢复生命，累计成绩和永久成长继续保留。

原录屏取材：355–374 秒。

## 03:54 合作的意义

合作也意味着互相支撑。生命耗尽后，一名玩家会暂时出局，但只要队友还在，战斗就可以继续。此时更需要谨慎走位，兼顾清敌和防守。成功过关后，双方恢复生命，重新加入下一段远征。

原录屏取材：492–521 秒。

## 04:23 守护这片花园

这就是暮光花园。用不同职业搭配，守住每一波进攻，再把战斗收获带入下一次远征。感谢观看。

原录屏取材：334–341 秒。
