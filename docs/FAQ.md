# 常见问题

[返回项目说明](../README.md) · [操作与关卡](GAMEPLAY.md) · [存档与语言](SAVES_AND_LANGUAGE.md)

## 导入后仍然看到旧界面

确认导入的是 [版本与下载](VERSIONS.md) 标为当前版本的项目包，文件名含版本号，并运行这次导入的项目。当前版本的入口是带“开始游戏、读档、设置、实验室”四个按钮的动态首页，页脚显示版本号。下载新版文件不会更新已经导入的旧项目。

## 为什么只能进入第一关

这是新档的正常状态。通关第一关会解锁第二关，之后依次解锁。灰色锁图标表示尚未开放；方向键和主题快捷键可以浏览关卡，但不能绕过锁定。已经解锁的关卡可以重玩。

旧版存档若保留了最高通关记录，会继承该记录；只有金币的 TG1 存档没有关卡记录，因此从第一关开始。

## 已选关卡，为什么还没进入战斗

选关后会进入职业页。先选择单人 / 双人，分别选好职业，再点击“进入战场”或按 Enter。选关页的 Enter 是进入职业页，职业页的 Enter 才是确认开战。

## 键盘没有反应，或大招不能连续释放

先点击游戏区域，使游戏获得键盘焦点。1P 使用 WASD、空格、E；2P 使用方向键、J、K。确认没有停留在编辑器的代码输入框、浏览器对话框或暂停状态。

普通攻击可按住，大招需要松开后再按，并等待冷却结束；角色出局后无法攻击。若某组多人按键被键盘硬件限制，先尝试减少同时按下的键，再检查是否仍会发生。

## 双人可以选择不同职业吗

可以。职业页切换到双人合作，点击玩家切换按钮或按 Tab，分别为 1P / 2P 选择。1 / 2 / 3 对应豌豆 / 蘑菇 / 西瓜。

团队共享金币，但三个职业分别进化；两人选择同一职业时共用该路线的档位。换职业不会把另一条路线清零。

## 为什么实验室里的另一种植物没有升级

购买只作用于当前标签对应的职业。先确认顶部选中豌豆、蘑菇还是西瓜，再查看该路线的档位与下一次费用。每条路线都有免费基础形态，之后五次购买依次需要 100 / 250 / 500 / 900 / 1500 金币。

金币不足或已经达到第五档时不会扣费。升级费用来自击退敌人的收入；本版没有充值入口。

## 继续存档后，为什么生命恢复、敌人又出现了

存档记录的是关卡起点。继续会恢复生命、重建敌人和道具，不恢复半途位置、子弹、临时增益或 Boss 剩余血量。已获得金币与永久进化保留。详细范围见 [存档说明](SAVES_AND_LANGUAGE.md#存档范围)。

## 脑子屏障怎么被拆掉

僵尸接近脑子后会停下啃咬，累计有效啃咬三秒后屏障消失。多个僵尸不会加速，清掉或引走它们可中断损耗；耐久不自动恢复。屏障消失后再接触脑子才会失败。暂停不计时；重试、换关或继续关卡起点存档时恢复满屏障。

## 开始游戏和读档有什么区别

“开始游戏”让你重新选关和职业，并替换当前检查点；“读档 → 继续存档”恢复已经记录的关卡、人数、职业与起点得分。钱包和永久进化不随新局清空。

目前只有一个检查点。想保留当前存档再尝试新组合，先在读档页导出备份码。

## 换浏览器、换设备后找不到存档

存档使用当前浏览器配置和站点来源下的本机数据。不同浏览器、设备、账号配置或站点来源之间不会自动同步；XBuilder 登录状态也不等于游戏云存档。

在原环境中打开读档页，导出并保存完整备份码；到新环境的读档页恢复。恢复会替换目标环境的当前进度，操作前也可先备份目标环境。

## 显示“待存”或“存档损坏”怎么办

“待存”表示本次写入未能确认成功，游戏会尝试重试。先保持当前页面，尝试在读档页导出备份码；未确认保存前，不要把刷新或关闭页面当成修复方法。

“存档损坏”时程序会保留原数据。请恢复自己保存的有效备份；无效格式或校验失败的码不会替换现有进度。浏览器若同时限制存储与对话框，自动保存和备份可能都无法完成。

## 如何切换中英文

首页点击“设置”，选择中文 / English；也可以按 T。双方共用同一语言选择，操作按键保持一致，语言偏好会随本机存档保存。

## 图片和动图是实机录像吗

README 中的首页、职业与 Boss 动图由项目实际素材合成，用于展示造型、排版和技能时序。来源见 [媒体说明](media/README.md)。目前已完成规则、存储、编译和资源检查，XBuilder 在线整体验收仍待完成。

## 遇到其他问题，提供什么信息最有帮助

请记录项目包名称、进入的页面、关卡、单双人模式、双方职业与档位、操作步骤，以及预期和实际表现。与存档有关时说明是新档还是旧档迁移、是否出现待存或损坏提示；这能帮助区分规则问题、旧项目和浏览器存储问题。
